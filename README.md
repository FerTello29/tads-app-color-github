### Descripción

En esta práctica se trabaja con la publicación colaborativa de un proyecto de software, utilizando herramientas de control de versiones y plataformas de colaboración para facilitar el trabajo en equipo.

## Objetivo

Aplicar los conocimientos adquiridos sobre publicación y colaboración en proyectos de software, utilizando herramientas como Git y GitHub para gestionar el código fuente y facilitar el trabajo colaborativo.

---

## Conclusión

Esta práctica permitió reforzar el uso de herramientas de colaboración y control de versiones. Además, ayudó a comprender mejor cómo organizar y publicar un proyecto para trabajar de manera conjunta con otros integrantes.
